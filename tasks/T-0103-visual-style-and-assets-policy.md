# T-0103 · 视觉风格、命名图标、素材规范

## 目标
确定 App 的名字、图标方向、配色 / 字体 / 圆角 / 动效风格，以及内置素材（字体、音乐、贴纸、LUT）的来源和许可证规则。

## 范围
**做：**
- `docs/product/visual-style.md`：设计令牌（颜色、字体、间距、圆角、阴影）、深色模式、动效原则；提供 2–3 个风格方向让用户选（可以用 HTML 生成预览截图）。
- App 名称和图标：给出几个候选。
- 素材规范：每类素材的候选来源（OFL 字体、CC0 音乐、自绘 / CC0 贴纸、自己生成的 LUT）+ 登记格式（将来的 `app/Resources/LICENSES.md`）。

**不做：** 绘制全部贴纸（T-0406）、制作模板（T-0506）。

## 验收标准
- [ ] AC1：visual-style.md 完成，用户选定风格方向。
- [ ] AC2：App 名称确定（PRD Q4 关闭）。
- [x] AC3：素材规范写明每类素材的来源和许可证要求。 证据：visual-style.md 素材来源表及 LICENSES.md 字段已逐类核对。

## 需要用户提供 / 确认
- 风格偏好；朋友喜欢的颜色 / 元素（可以作为彩蛋）；App 名称。

## 实施要点
- 设计三组 macOS 主题、命名和图标方向，推荐一组供工程使用。
- 给出亮暗配色、字号和动效等令牌，验证关键前景/背景对比并给出素材许可登记规范。
