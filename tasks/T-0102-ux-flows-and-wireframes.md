# T-0102 · 交互流程与线框图

## 目标
给每个 P0 页面画出线框和交互流程，让后续 UI 任务有明确的"长什么样、点哪里去哪里"。

## 范围
**做：**
- `docs/product/ux-flows.md`：页面清单、页面跳转图、关键流程（修图 3 步、短片 3 步、生日当天首次打开）。
- 每个 P0 页面一张线框（先用 ASCII / Markdown；如果需要更直观，可以用 HTML 原型生成截图）。
- 按 [ux-principles.md](../docs/product/ux-principles.md) 逐条自查。

**不做：** 配色和视觉细节（T-0103）。

## 验收标准
- [x] AC1：ux-flows.md 覆盖所有 P0 页面和 3 条关键流程。 证据：ux-flows.md 列出 11 张页／面板线框及 P0 映射。
- [x] AC2：每个流程都满足"3 步内完成"的原则（在文档里标出步数）。 证据：三条路径表逐步列出默认任务阶段，均在三步内。
- [ ] AC3：用户确认（`review` → `done`）。

## 实施要点
- 按 PRD v1.0 枚举每个 P0 页面与状态，写 ASCII 线框，标出默认任务步数。
- 假设：导航从任务入口开始计步，系统选择器确认计入所在步骤，同时列出从首页到入口的操作。
- 列出快捷键的焦点规则和十条易用性对照。
