## 结论速览（看完这 6 条就够了）

1. 用户看到的"把 PS 重构成很小的开源程序"= **Compositor**（Swift、MIT、约 8.9MB、**只支持 macOS 26+ 和 Apple 芯片**）。它不能装到 iPhone 上。
2. iOS 上**没有**可以直接改的全功能开源底座，正确做法是**原生 Swift + 系统框架 + 少量宽松许可的开源库**。
3. 视频剪辑**不需要 FFmpeg**（ffmpeg-kit 已归档，而且是 LGPL），AVFoundation 就够用。
4. 最大的障碍不是技术，而是**没有 Mac**：只能靠云端 macOS 构建。
5. 让朋友用上：**iOS 版**要 $99/年，TestFlight 构建 90 天过期，长期分发要走 Unlisted 审核；**Mac 版**可以 ¥0 直接发安装包，朋友第一次打开时手动点一次"仍要打开"就行。
6. "简单易用 + 大多数效果" = **模板化 + 一键操作**，不要把 PS 的面板搬过来。
