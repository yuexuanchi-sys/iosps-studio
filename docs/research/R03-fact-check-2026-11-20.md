- Requirements 原文："macOS 26.0 or later on a Mac with Apple silicon"、"Xcode 26 or later (to build from source)"；"Compositor is macOS only"。

## 3. 调研遗漏的关键点（对执行影响很大）

### 3.1 "谁写代码、在哪里验证" —— 调研完全没覆盖
两份报告的工期都是按"熟练 iOS 开发者在 Mac 上开发"估算的。实际情况是：**AI 在 Windows 上写代码，没有 Mac 可以本地编译和预览**。由此带来的变化：
- 每一次编译、测试都要推到云端 macOS（GitHub Actions），**一轮反馈约 5–15 分钟**，这才是节奏上的瓶颈，不是写代码本身；
- UI 没法实时预览 → 需要一条**截图验证管线**：CI 跑快照测试或 UI 测试，产出 PNG 截图，AI 读图检查、用户确认（见 [verification.md](../workflow/verification.md)）；
- 应对：架构上把**纯逻辑**（工程模型、模板、时间轴计算、倒计时等）做成纯 Swift 模块，不依赖 Apple 框架，这样在 Windows 上装 Swift 工具链就能本地跑单测（ADR-0006）。

### 3.2 云端 macOS 构建的现实条件（新核实）
- GitHub Actions 已提供 `macos-26`（Apple 芯片，2026-02-26 正式可用）和 `xcode-27` 镜像（2026-10-15 正式可用，运行在 macOS 27 上）。来源：[GitHub Changelog · macos-26 GA](https://github.blog/changelog/2026-02-26-macos-26-is-now-generally-available-for-github-hosted-runners/)、[GitHub Changelog · Xcode 27 image GA](https://github.blog/changelog/2026-10-15-xcode-27-runner-image-generally-available/)
- 计费：**公开仓库使用标准 runner 免费**；私有仓库按分钟扣每月免费额度，macOS 标准 runner 2026-01-01 起约 **$0.062/分钟**（第三方汇总数据，**以 GitHub 官方账单页为准**）。来源：[cicdcalculator · 2026 pricing changes](https://cicdcalculator.com/github-actions-pricing-changes-2026)、[Lizard · Actions pricing 2026](https://lizard.build/blog/github-actions-pricing)
- 推论：**公开仓库 + 个人素材绝不入库**，是零成本又安全的组合（D-04）。

### 3.3 Xcode 工程文件不适合在 Windows 上手写
`.xcodeproj/project.pbxproj` 是机器生成的格式，在 Windows 上手工维护很容易出错。应对：用 **XcodeGen**（MIT，活跃）根据 `project.yml` 在 CI 上生成工程；纯逻辑模块用 SwiftPM（ADR-0004）。另外有报道说 Xcode 27.2 引入了新的 JSON 工程格式（来源：[DEV · Xcode 27.2](https://dev.to/arshtechpro/xcode-272-what-developers-need-to-know-including-the-new-json-project-format-2bn2)，**待核实**），可以作为后续备选。

### 3.4 iOS 版的零成本自测路线（**待实测**）
不花 $99 也能把开发版装到**用户自己的** iPhone 上自测：CI 构建一个未签名的 IPA → 在 Windows 上用 Sideloadly / AltStore 配合免费 Apple ID 签名安装（7 天有效）。**只适合开发自测，不适合送礼。**

### 3.5 R02 的前提假设未经确认
R02 整篇默认"朋友常用 MacBook"。用户最初只说了 iPhone 14，以及"如果 iOS 太难就做 MacBook 版"。**朋友有没有 MacBook、是什么芯片和系统版本（D-07）是平台决策的前提**：
- 如果是 Intel Mac，或者系统低于 macOS 26 → 不能参考复用 Compositor 的代码，Mac 版就要走自研轻量引擎；
- 如果没有 Mac → 只能做 iOS 版。

## 4. 对两个核心问题的复核结论

| 问题 | iOS 版（iPhone 14） | Mac 版（朋友的 MacBook） |
|---|---|---|
| **开发难度**（AI 写代码 + 云端构建） | 中等偏高：编辑器手势交互多，UI 只能靠截图验证；真机测试需要签名 | 中等：同样靠截图验证，但构建出来直接就是可运行的 .app，不需要签名配置 |
| **让朋友真正用上** | 需要 $99/年；TestFlight 体验（90 天过期）→ Unlisted 审核后长期使用；额外预留约 1–2 周处理账号、签名和审核 | ¥0：CI 产出 zip → 发给朋友 → 首次打开点"仍要打开"并输入密码；可选 $99 公证去掉警告 |
| **结论** | 可行，但前置门槛（账号 + 签名 + 审核）明显更高 | **如果朋友有 Apple 芯片的 Mac，优先做 Mac 版**；核心模块以后可以复用到 iOS 版 |
