# 项目章程（Charter）

- **版本**：v0.1（2026-11-20）
- **状态**：草案，等用户确认 D-02 后定稿（见 [STATUS.md](../STATUS.md)）

## 1. 为什么做

给朋友一份**能长期用下去**的生日礼物：不是只看一次的电子贺卡，而是一个朋友日常真的会打开的 P图 / 剪辑工具，同时装满两个人的回忆和惊喜。

## 2. 目标

| # | 目标 | 衡量方式 |
|---|---|---|
| G1 | 生日前交付一个**能装上、能打开、不崩**的版本 | 在朋友的目标设备上完成验收清单（T-0803） |
| G2 | **简单易用**：没教过的人也能 3 步内完成一件事 | 修图：选图 → 选预设/调整 → 保存；短片：选素材 → 选模板 → 导出 |
| G3 | **实用**：覆盖日常大多数修图和剪辑需求 | P0/P1 功能都能用（见 [features.md](product/features.md)） |
| G4 | **有礼物感**：生日主题体验、回忆、彩蛋 | 生日主页、回忆时间轴、至少 1 个彩蛋 |
| G5 | **长期可用**：不会 7 天 / 90 天后失效 | 分发方式满足"长期"（见 ADR-0005） |

## 3. 约束

| 约束 | 说明 |
|---|---|
| 开发机只有 Windows | 没有 Mac，Apple 平台构建全部依赖云端 macOS（ADR-0004） |
| 目标设备 | M 系列 MacBook，最低 macOS 14.0；L4 核对实际系统版本（D-07） |
| 截止日期 | 朋友生日（**待确认，D-02**），按截止日倒排工期 |
| 预算 | 尽量 ¥0；$99/年开发者账号待确认（D-03） |
| 无后端 | 不做账号、云同步、社区；所有处理在本机完成，不收集数据 |
| 许可证 | 只用宽松许可的依赖和素材（见 CLAUDE.md 硬规则） |

## 4. 范围

- **做**：生日体验层（主页、倒计时、回忆、彩蛋、祝福）+ 工具层（P图、一键回忆短片、基础剪辑）。详见 [features.md](product/features.md)。
- **不做**：专业图层编辑、多轨时间轴、关键帧、账号/云/社区、内购、AR（放到最后视情况）。详见 [ux-principles.md](product/ux-principles.md) §不做清单。

## 5. 角色

| 角色 | 谁 | 职责 |
|---|---|---|
| 产品负责人 / 验收人 | 用户 | 拍板决策、提供礼物素材、真机验收、把 App 交给朋友 |
| 开发 | AI（Claude Code）为主（待确认，D-06） | 文档、设计、代码、CI 配置、自测 |
| 最终用户 | 朋友 | 使用礼物（开发过程中对 TA 保密） |

## 6. 里程碑（概要，详见 [tasks/BOARD.md](../tasks/BOARD.md)）

M0 决策与环境 → M1 产品定义 → M2 工程骨架与 CI → M3 礼物体验 → M4 照片编辑 → M5 一键回忆短片 → M6 视频剪辑 → M7 增强功能 → M8 打包分发与交付
