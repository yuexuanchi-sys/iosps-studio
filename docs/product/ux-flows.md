# macOS 交互流程与线框

首版用一个主窗口，默认打开生日主页。侧栏切换场景，工具栏保留每页的主要动作。以下线框对应 [PRD v1.0](prd.md) 与 [P0 清单](features.md)，为 T-0102 评审稿。

## 页面和跳转

| 页面或系统面板 | 功能 | 入口与去向 |
|---|---|---|
| 初次打开 / 导入回忆 | F-01、F-02 | 无礼物时自动出现；打开回忆文件夹后到主页，跳过则用示例 |
| 生日主页 | F-01、F-04 | 首屏；全屏祝福退出后返回这里 |
| 全屏祝福 | F-05 | 当天首次开启自动展示；主页可重播 |
| 彩蛋面板 | F-03 | 主页爱心触发；关闭后焦点回到爱心 |
| 回忆时间轴 | F-02 | 侧栏「回忆」；选照片到详情 |
| 照片详情 | F-02 | 上下张、修图、短片；返回保持年份与滚动位置 |
| 照片编辑器 | F-06–F-14 | 侧栏「修图」→ 选图； Finder 拖入或回忆详情可直接打开 |
| 文件保存和结果 | F-13、F-15 | 系统文件面板 → 后台导出 → 结果 |
| 短片素材选择 | F-06、F-15 | 侧栏「回忆短片」→ 选取排序素材 |
| 短片模板和预览 | F-15 | 确定素材后进入；更换模板原地刷新 |
| 关于与许可 | F-26 | App 菜单「关于」→「许可与致谢」 |

```text
启动 → 有礼物：生日当天首次 → 全屏祝福 → 主页
     → 有礼物：其它时间 ────────────→ 主页
     → 无礼物 → 打开回忆／看示例 ────→ 主页
主页 → 爱心 → 彩蛋 → 主页
主页 → 回忆 → 照片详情 → 修图／短片
侧栏修图 → 选图 → 编辑器 → 保存 → 查看文件
侧栏短片 → 选素材 → 选模板并预览 → 导出 → 查看文件
App 菜单 → 关于 → 许可与致谢
```

## 三条默认路径

一步是完成一个任务阶段。系统文件面板内的选取与确认属于同一步。侧栏定位是进路径前的一次操作，首页也可直接拖文件到工具入口。

| 路径 | 第 1 步 | 第 2 步 | 第 3 步 |
|---|---|---|---|
| 修一张图 | 从 Finder 选取或拖入照片 | 点预设，也可在本步微调 | 保存，确认文件位置 |
| 做一支短片 | 选取或拖入照片／视频，默认按选取顺序 | 选模板并在同页播放预览 | 导出，确认 MP4 位置 |
| 生日当天首次 | 启动 App | 首次导入回忆文件夹；已预导入时自动跳过 | 祝福播完或按 Esc 回到主页 |

## 页面线框

### 1. 初次打开与回忆导入

```text
+-----------------------------------------------+
| 生日主页                                      |
|                                               |
| 打开朋友准备的回忆                            |
| [打开回忆]       [先看看示例]                 |
| 文件验证进度… [取消]                          |
| 失败时显示原因、[重新选择]、[继续使用当前回忆] |
+-----------------------------------------------+
```

选择文件夹先验证，再替换当前礼物。缺文件时指出清单条目及修复方式。进程中断或取消，保留此前成功导入的版本。

### 2. 生日主页与语音祝福

```text
+--------+-------------------------------------------+
| 生日   |      精选照片                             |
| 回忆   |      朋友的祝福文字                       |
| 修图   |      距生日 · 年龄 · 相识天数             |
| 短片   |      [播放祝福]  [暂停]  [停止]  [爱心]  |
|        |      [重播生日祝福]                       |
+--------+-------------------------------------------+
```

指标缺日期即隐藏。离开页面停止播放。示例内容带「示例」标签，可在「文件」菜单重新导入。

### 3. 全屏祝福

```text
+------------------------------------------------------+
|                                              [跳过]  |
|                                                      |
|                  生日快乐                            |
|                  朋友的祝福文字                      |
|                  [回到主页]                          |
+------------------------------------------------------+
```

生日当天一次自动触发。减少动态效果时直接呈现文字与静态背景。Esc 返回，完成后焦点回主页标题。

### 4. 彩蛋

```text
+---------------------------------+
| 彩蛋                      [关闭]|
| 朋友准备的一句话或一幅图        |
|                 [回到生日主页]  |
+---------------------------------+
```

连点爱心打开。爱心的辅助功能及键盘菜单等价动作可直接激活，闭合时恢复原焦点。

### 5. 回忆时间轴

```text
+-------+--------------------------------------------+
| 回忆  | 回忆                       [按年份定位]   |
|       | 2024                                       |
|       |  星期天 · 一句话                          |
|       |  [照片 1] [照片 2] [照片 3]               |
|       | 2023                                       |
|       |  旅行 · 一句话 [照片 4]                   |
+-------+--------------------------------------------+
```

预先显示缩略图，图片可按键盘次序聚焦。无回忆时给示例与导入入口。

### 6. 照片详情

```text
+----------------------------------------------------+
| [返回时间轴]  [上一张] [下一张]  [修图] [做短片]   |
|                                                    |
|                      照片                          |
|                                                    |
|                日期 · 事件说明                     |
+----------------------------------------------------+
```

左右箭头切图，Esc 回列表并定位原缩略图。修图和短片预选当前照片。

### 7. 照片编辑器

```text
+--------+------------------------------------------------+
| 修图   | [打开]      [撤销] [重做]         [保存]      |
|        +--------------------------------+---------------+
|        |                                | 滤镜          |
|        |            代理图画布          | [原图] [预设] |
|        |         [按住空格对比]         | [强度滑杆]    |
|        |                                | [高级参数]    |
|        +--------------------------------+---------------+
|        | 裁剪 调整 滤镜 文字 贴纸 涂鸦 马赛克           |
+--------+------------------------------------------------+
```

空状态显示「选一张照片」与拖放区。默认展示预设，工具选中后右侧只显示该工具控件。滑杆拖动实时预览，释放提交一次撤销记录。重开自动进入最近有效草稿，可在工具栏打开其他文件。

### 8. 保存 / 导出及结果

```text
+-------------------------------------------+
| 保存照片／导出短片                       |
| 名称 [             ]   位置 [         ]   |
| 格式 [JPEG / PNG 或 1080p MP4]           |
|                    [取消] [保存／导出]    |
+-------------------------------------------+
| 处理中 [====     ]  [取消]               |
| 失败：原因 [重试] [更改保存位置]         |
| 完成：[在 Finder 中显示] [分享]          |
+-------------------------------------------+
```

输出依次经过系统面板、进度、结果。取消与失败时保留草稿，成功后才亮起分享按钮。

### 9. 短片素材选择

```text
+----------------------------------------------------+
| 回忆短片 · 选素材                [继续选择模板]    |
| [从 Finder 添加]  [从回忆选择]                     |
| 1 [照片]   2 [照片]   3 [短视频]                    |
| [前移] [后移] [移除]    支持拖放                   |
| 无项目时显示示例，导入失败项单独列出               |
+----------------------------------------------------+
```

选中项按导入顺序排列，键盘可调整顺序。确认后直接加载推荐模板及预览。

### 10. 短片模板与预览

```text
+----------------------------------------------------+
| [改选素材]                [播放／暂停] [导出]      |
|                      视频预览                      |
|               [播放位置滑杆] 00:00                 |
| [推荐模板] [其它模板缩略图横排]  [模板详细设置]     |
+----------------------------------------------------+
```

换模板时保留原素材和排序，处理异常可返回素材选择或换模板。预览就在模板页，无独立确认页。

### 11. 关于和许可与致谢

```text
+---------------------------------------------+
| 关于                                  [关闭]|
| App 名称 · 版本                             |
| [许可与致谢]                                |
+---------------------------------------------+
| 许可与致谢                            [返回]|
| [组件／字体／音乐／贴纸／模板]              |
| 资源名 · 来源 · 许可文本 · 版权声明         |
+---------------------------------------------+
```

许可在离线状态可读，链接作为来源附加信息。

## 键盘与反馈

| 操作 | 快捷键及焦点条件 |
|---|---|
| 打开、保存照片／导出短片 | ⌘O、⌘S；命令随当前场景提供，忙时禁用重复导出 |
| 撤销、重做 | ⌘Z、⇧⌘Z；文字输入时优先交给文字控件 |
| 对比原图 | 仅照片画布接收按住空格，失焦时释放；工具栏有可聚焦的对比按钮 |
| 播放／暂停 | 空格在短片预览区域生效，聚焦文本或按钮时保留其系统行为 |
| 退出面板或全屏 | Esc；恢复发起动作的焦点 |
| 走查控件 | Tab／Shift+Tab；侧栏 → 工具栏 → 画布 → 检查器 → 底部工具 |

## 易用性自查

| 原则 | 线框对应 |
|---|---|
| 1. 首屏入口 | 回忆、修图、短片，设置进 App 菜单 |
| 2. 模板优先 | 默认推荐模板和滤镜，详细选项折叠 |
| 3. 三步完成 | 上表三条路径均 ≤ 3 个任务阶段 |
| 4. 操作可达 | 底部编辑工具、工具栏主动作、菜单快捷键 |
| 5. 即时反馈 | 代理图更新、原图对比、模板页直接预览 |
| 6. 草稿安全 | 恢复有效草稿，取消和失败不丢内容 |
| 7. 空状态 | 礼物、回忆和两项工具提供示例或导入 |
| 8. 文案 | 自写祝福，入口用直接动词 |
| 9. 性能 | 缩略图、可取消的后台导出、进度与恢复 |
| 10. 无障碍 | 焦点、VoiceOver、键盘、文字缩放、深色、减少动态效果纳入 L3/L4 |
