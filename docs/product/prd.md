## 2. 核心场景

| 场景 | 朋友的目标 | 成功条件 |
|---|---|---|
| 生日前后首次打开 | 收到祝福和回忆 | 已导入时直接进入生日主页；生日当天首次展示全屏祝福，可退出 |
| 日常修图 | 选图、套预设、保存 | 默认做法分三步；失败保留草稿和原件 |
| 分享回忆短片 | 选一组素材、选模板、导出 | 默认做法分三步；导出结果有明确位置 |
| 日常剪辑（P1） | 拼接、裁掉废片、加文字或音乐 | 单条主画面时间轴，按 F-16–F-20 验收 |

## 3. macOS 信息架构

主窗口侧栏提供「回忆」「修图」「回忆短片」三个首版功能入口，单设生日主页作为侧栏顶部标题按钮。「剪辑」随 P1 启用。顶部工具栏提供导入和保存 / 导出，照片编辑使用中央画布、底部工具及右侧检查器。菜单提供打开、撤销、重做、保存，设置和许可位于菜单。无素材时可看示例或导入。

礼物使用独立的本地文件夹。用户在可信渠道私下传给朋友，朋友第一次打开可以选择「打开回忆」，也可以由用户提前在目标 Mac 上导入。App 先验证清单和引用，再将一份完整副本写入本机应用数据目录，失败时保留上一份可读内容。跳过可使用示例和工具，之后可从「文件 → 导入回忆」补录。安装包和 CI 只用公开资源。

## 4. P0 故事与验收

| ID | 作为朋友，我想…… | 关键验收 |
|---|---|---|
| F-01 | 一打开就看到祝福和我们的日子 | 已导入时展示祝福、精选照片、倒计时、年龄及相识天数；缺日期时隐藏对应数字，日期按本机日历，闰日策略有单测 |
| F-02 | 按时间找到一张回忆照片 | 年份和事件可浏览，详情能返回原位置，可将该图送入修图或短片；缺素材有可恢复提示 |
| F-03 | 发现可以打开的彩蛋 | 连点爱心触发，键盘和 VoiceOver 有等价入口；只有成功触发后展示彩蛋内容 |
| F-04 | 听朋友录的祝福 | 明确播放、暂停、停止，离开时停止；缺音频时保留文字祝福 |
| F-05 | 在生日当天收到全屏祝福 | 当天首次打开展示一次，同日可手动重播；有跳过和减少动态效果 |
| F-06 | 从 Finder 选取或拖入照片和视频 | 照片支持 JPEG、PNG、HEIC，视频支持常见可解码的 MOV、MP4；混合导入列出失败项并保留有效项 |
| F-07 | 裁掉边缘、旋转或翻转照片 | 裁剪提供自由、原始及常用比例；四次 90° 旋转回到原方向，每一步可撤销 |
| F-08 | 修正照片的明暗与色彩 | 亮度、对比度、饱和度、曝光、色温、高光阴影、锐化和暗角可预览、重置 |
| F-09 | 快速预览并套用滤镜 | 至少 12 个自制预设，显示缩略预览和当前选择，能恢复原图 |
| F-10 | 在照片上写一句话 | 字体、颜色、描边、阴影和位置可调，画布与导出位置一致 |
| F-11 | 在照片上加生日贴纸 | 可添加、移动、缩放和删除内置贴纸，导出保留位置 |
| F-12 | 画线标记或打码 | 提供笔刷与马赛克，笔迹位置与导出一致，支持撤销 |
| F-13 | 保存成能分享的照片 | 文件保存支持 JPEG / PNG；按原图尺寸渲染，裁剪时按裁剪区尺寸输出；取消和失败保留编辑状态，导出后可系统分享 |
| F-14 | 改错后撤销，重开 App 继续做 | 至少能撤销 20 个提交动作，重做可回放；新编辑清空重做；重开恢复最近成功保存的草稿 |
| F-15 | 用照片和视频快速做一支短片 | 至少 8 个模板；模板即时生成可播预览，默认导出 1080p MP4；导出支持进度、取消和重试 |
| F-26 | 看见素材和组件来自哪里 | 「关于」可打开许可与致谢，显示来源、许可文本和必要的版权声明 |

## 5. 质量基线

| 类别 | 要求 |
|---|---|
| 部署 | M 系列 MacBook、macOS 14.0 起，构建 arm64（D-07） |
| 性能 | 以 MacBook Air M1、8 GB 作为设计参考；代理图预览目标 ≥ 30 fps，目标 Mac 上 1 分钟 1080p 短片导出目标 ≤ 2 分钟，L4 待实测。见 [平台 ADR](../decisions/ADR-0003-target-platform.md) |
| 稳定 | 草稿自动保存、有效草稿可恢复、原始媒体只读；导出可取消，失败显示原因和下一步 |
| 隐私 | 本地处理及存储，无账号、遥测和云传输；必要权限在使用时申请 |
| 安装 | 基础安装包目标 ≤ 80 MB；ZIP 签名及完整性由 CI 检查，首次运行和离线使用由目标机验收 |
| 无障碍 | 完整键盘路径、可见焦点、VoiceOver 标签、系统深色模式、减少动态效果、文字缩放 |

## 6. 范围边界

按 [易用性原则](ux-principles.md) 收敛编辑器，长期保留所需的单轨视频编辑和非破坏性照片编辑，优先把普通用户的默认流程做短。
