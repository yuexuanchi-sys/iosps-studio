# 易用性原则 & 不做清单

> 来源：[R01 §5.3、§5.4](../research/调研报告.md)。做任何 UI 任务前先读一遍；评审 UI 截图时按这里逐条检查。

## 十条原则

1. **首屏最多 4 个入口**：回忆、修图、回忆短片、剪辑（设置藏在角落）。
2. **模板优先**：先选模板 / 预设，再换图、改字，最后导出；专业参数折叠进"高级"。
3. **3 步内完成一件事**：修图 = 选图 → 预设 / 调整 → 保存；短片 = 选素材 → 选模板 → 导出。
4. **主操作容易找到**：Mac 底部工具栏、顶部主操作和快捷键（⌘Z / ⌘S / 空格播放）。
5. **即时反馈**：所有调整实时预览；长按（Mac 上按住空格）对比原图；操作有轻微动效。
6. **永不丢内容**：自动保存草稿，退出重进可以恢复；撤销 / 重做至少 20 步。
7. **没有空白页**：没素材时给示例和引导。
8. **文案有人情味**：中文默认字体苹方；祝福文案用用户自己写的话，不要模板腔。
9. **性能兜底**：大图先显示缩略图，后台渲染，有进度条，可以取消。
10. **无障碍**：VoiceOver 标签、动态字体、对比度达标，深色模式跟随系统。

## Snapseed 式调参手势（推荐）

Mac 用滑杆和键盘微调，滚轮仅在对应控件获得焦点时调整数值。

## 不做清单（防止做成"半成品 PS / PR"）

| 不做 | 理由 |
|---|---|
| 多图层混合、蒙版、通道、Camera Raw | 专业功能，违背"简单易用" |
| 多轨时间轴、关键帧、曲线变速、逐帧预览 | 工作量巨大，礼物场景用不上 |
| 4K 60fps 多轨、超过 10 分钟的长视频 | 性能风险高 |
| 账号、云同步、社区、内购、广告 | 礼物不需要，还会带来审核和隐私问题 |
| 冷门格式导入（MKV/AVI 等） | ADR-0002 |
| 依赖 Apple Intelligence 的功能 | 首版覆盖 Apple 芯片 macOS 14.0，本功能不作为基础配置假设 |
