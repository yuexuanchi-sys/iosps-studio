# 视觉方向与素材规范

暂按「暖色纸相册」和候选名「拾光簿」设计。礼物页使用暖背景、较大的留白和照片，工具页保持单色画布及明确的操作层级。最终选择由 T-0103 验收。

## 三个候选方向

| 方向 | 名称候选 | 图标构想 | 交互气质与取舍 |
|---|---|---|---|
| A. 暖色纸相册（推荐） | 拾光簿 | 珊瑚色圆角方形内叠放两张白色照片，前景一枚四角星 | 祝福和回忆有温度，编辑页用中性底保持色彩判断 |
| B. 植物印记 | 岁岁集 | 松绿色背景上的白色叶片与照片角 | 色调平静，适合旅行回忆，可把生日动效做成叶片与光点 |
| C. 夜蓝放映室 | 小幕间 | 夜蓝圆角方形内一帧浅蓝色放映窗 | 适合短片预览，礼物页用大幅照片与暖色祝福补足亲切感 |

查看名称候选时可交叉挑选图标和配色。图标在 16 pt 仍须辨认主轮廓，提供 16、32、128、256 和 512 pt 的 @1x/@2x 验收稿。名称为内部候选，正式公开前再做名称冲突核查。

## 色彩令牌

每格依次为浅色 / 深色。深色跟随系统，可在 L3 截图核对。工具画布背景统一为浅色 `#E7E7E7`／深色 `#171717`，放在照片周围。

| 令牌 | A 暖色 | B 植物 | C 夜蓝 |
|---|---|---|---|
| 背景 | `#FFF8F1` / `#271E1B` | `#F5F3EA` / `#192721` | `#F0F3F9` / `#191F30` |
| 面板 | `#FFFFFF` / `#352824` | `#FFFFFF` / `#24352C` | `#FFFFFF` / `#252D45` |
| 主文字 | `#30231F` / `#FFF1E8` | `#1E322A` / `#EFF9F0` | `#212D4A` / `#F0F3FF` |
| 次文字 | `#6D5047` / `#DEC0B2` | `#4B6256` / `#B6CFC1` | `#4A5978` / `#BAC6E5` |
| 主按钮背景 | `#963D31` / `#F5A99A` | `#316343` / `#A5D5AC` | `#375D9B` / `#ACC9FF` |
| 主按钮文字 | `#FFFFFF` / `#30201B` | `#FFFFFF` / `#1C3525` | `#FFFFFF` / `#192E55` |
| 焦点描边 | `#885038` / `#F5A99A` | `#316343` / `#A5D5AC` | `#375D9B` / `#ACC9FF` |

静态核对了三套主题的浅深组合。主文字／背景、次文字／面板、按钮字／按钮底、焦点／面板这四组的最低对比度分别为 A 6.46:1、B 6.60:1、C 6.56:1。小字号文字按至少 4.5:1 设计，焦点按至少 3:1，叠在照片上时增加不透明底。实际窗口状态仍在 L3 验证。[WCAG 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [WCAG 非文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

| 令牌 | 规范 |
|---|---|
| 字体 | 系统界面默认字体与中文系统回退；正文 14 pt、辅助 12 pt、标题 22 pt、生日主标题 36 pt；字号按辅助设置增长 |
| 间距 | 4、8、12、16、24、32 pt；侧栏宽 192–224 pt，检查器宽 232–280 pt，窄窗口保留画布优先 |
| 圆角 | 按钮 8 pt、面板 12 pt、照片和礼物卡 16 pt |
| 阴影 | 礼物照片提升用 0/4/16 pt、黑色 12%，深色降为边框分隔；编辑器面板以分隔线区分 |
| 动效 | 按钮反馈 120 ms，面板淡入 180 ms，庆祝单次彩带 ≤ 1.5 s；减少动态效果时切换到静态构图 |
| 排版状态 | 键盘焦点用 2 pt 轮廓，错误包含文字与图标，选中态包含标记；浅深和窗口失焦均纳入 L3 截图 |

## 素材来源与登记

| 类型 | 首选 | 备选和许可条件 |
|---|---|---|
| 字体 | 使用系统字体，由系统提供 | 需要打包时逐字体验证 OFL，保留许可和版权信息；候选 [Noto Sans CJK](https://github.com/notofonts/noto-cjk) |
| 音乐 | 自录且有分发权，或使用本地用户素材 | 候选 [Wikimedia Commons CC0 分类](https://commons.wikimedia.org/wiki/Category:CC-Zero)；逐音轨确认作品和录音许可 |
| 贴纸与图标 | 项目自绘原创形状 | 候选 Wikimedia Commons CC0 分类，逐件确认图案许可与来源 |
| LUT | 用项目内公式生成原创 LUT，登记配方和生成版本 | 外部预设必须可核实为允许分发的宽松许可 |
| 模板与示例照片 | 项目原创模板、项目绘制的示例 | 示例可选 [Wikimedia Commons CC0 分类](https://commons.wikimedia.org/wiki/Category:CC-Zero)，以单文件许可为准 |
